## Overview

T-Guide is a route-based guided audio system.

The platform compiles narrated driving routes offline and produces route-constrained GPS trigger zones and runtime manifests.

The system separates:

- Compile-time route processing
- Runtime GPS trigger detection
- Conditional audio selection
